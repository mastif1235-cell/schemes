# Кандидат 3.4.9

Дата: 2026-09-13. Ветка: `codex/notebook-conflicts-notes-viewer-349`.

Production Worker, D1 и GitHub Pages не изменялись: для них требуется отдельное подтверждение.

## Причина старых конфликтов `notebook`

Базовая `queueEntityChange()` добавляла новую строку outbox для каждого локального изменения блокнота без дедупликации и без снимка исходных полей. `PATCH /api/notebooks/:id` корректно возвращал 409 при устаревшей `revision`. Клиент переводил каждую такую строку в `conflict`, а повторная синхронизация выбирала только `pending` и `failed`. Интерфейса разрешения конфликтов блокнота не было, поэтому 12 старых записей не могли покинуть очередь.

В 3.4.9 новые изменения одного блокнота используют одну активную строку outbox. Старые конфликты группируются по блокноту и сверяются с актуальной серверной копией. Полностью совпадающие данные закрываются автоматически с обновлением ревизии. При реальном различии пользователь сравнивает версии и выбирает серверную или локальную; все дубли закрываются, а для выбранной локальной версии остаётся ровно один PATCH.

## Изменения

- Любой активный OWNER/MEMBER может редактировать и мягко удалять любое примечание блокнота. Исходный `author_id` сохраняется; activity фиксирует текущего редактора или удалившего пользователя. Проверка ревизии и 409 сохранены, посторонний получает 403.
- Unread остаётся серверным состоянием пользователя. При прямом открытии разворота клиент сначала получает свежий unread, затем записывает spread cursor, поэтому новое примечание с другого телефона не оставляет ложный индикатор после просмотра.
- Нажатие на фото открывает отдельный fullscreen только с фото и контролами. Есть zoom, pan, double tap, 100%, свайп, верхнее закрытие; предыдущий/следующий находятся под фото. Закрытие возвращает к тому же развороту.
- Поле нового примечания занимает всю ширину, имеет минимальную высоту 96 px; кнопка находится ниже и также занимает всю ширину. Действия заметки компактны.
- Версия frontend/runtime: 3.4.9. Manifest и SW используют единый `version.json` bridge.
